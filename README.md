# Blah-blah
## BlockWorld (sandbox voxel 3D)

Abra `index.html` no navegador (precisa de internet para carregar o Three.js via CDN) e clique para jogar.

- **WASD** mover · **Mouse** olhar · **Espaço** pular · **Shift** correr
- **Clique esquerdo** quebrar · **Clique direito** colocar
- **1–9 / roda do mouse** escolher bloco · **Esc** pausar
